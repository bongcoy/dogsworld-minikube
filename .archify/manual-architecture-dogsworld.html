DogsWorld di Kubernetes dengan Datadog SSI

Arsitektur lab minikube di Podman (WSL2). Dibuat manual dari file proyek dan hasil kubectl, belum lewat gate Archify.

Alur request

  • Browser lewat port-forward ke Service
  • Service meneruskan ke pod DogsWorld
  • DogsWorld membaca data dari SQL Server

Instrumentasi SSI

  • Operator membuat Agent dari DatadogAgent
  • Cluster Agent menyuntikkan tracer .NET saat pod dibuat
  • Tidak ada tracer di Dockerfile atau kode

Rahasia dan data

  • API key di Secret datadog-secret, dibuat manual
  • Password SA di Secret sqlserver-secret
  • Data di PVC 2Gi, database Dogs dibuat Job db-init
